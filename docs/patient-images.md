# Patient card illustrations

Medical illustrations by Servier Medical Art, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Downloaded from the official library on 2026-10-17. Original PNG files are stored locally in `public/content/images/`. CSS adapts their color and opacity, fades the left edge, and scales them for decorative use. Attribution is displayed below the cards in both languages.

- `content/images/thyroid.png`: [Thyroid - Front view](https://smart.servier.com/smart_image/thyroid/), [original PNG](https://smart.servier.com/wp-content/uploads/2016/10/thyroide_face.png).
- `content/images/parathyroid.png`: [Thyroid - Posterior view](https://smart.servier.com/smart_image/thyroid-overview/), [original PNG](https://smart.servier.com/wp-content/uploads/2016/10/thyroide_post.png).
- `content/images/diabetes.png`: [Pancreas](https://smart.servier.com/smart_image/pancreas/), [original PNG](https://smart.servier.com/wp-content/uploads/2016/10/coupe_pancreas.png).
- `content/images/bone-health.png`: [Osteoporosis](https://smart.servier.com/smart_image/osteoporosis-view/), [original PNG](https://smart.servier.com/wp-content/uploads/2016/10/os_04.png).
- `content/images/metabolism.png`: [Adipocytes](https://smart.servier.com/smart_image/smart-adipocyte-overview/), [original PNG](https://smart.servier.com/wp-content/uploads/2016/10/adipocyte_07.png).
- `content/images/womens-health.png`: [Ovary](https://smart.servier.com/smart_image/ovary-smart-overview/), [original PNG](https://smart.servier.com/wp-content/uploads/2016/10/ovaire_2f.png).

Set an article's optional `image` field to a path relative to `public/content/`, such as `images/thyroid.png`. Upload replacement files and update the JSON to change artwork alongside patient content. Cards without an image retain their plain background.
